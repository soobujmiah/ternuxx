# Management client coverage

Ternuxx runs on Native Termux as the host and control plane, with optional Debian PRoot workloads. This table describes current source paths. Native `proot`/`proot-distro` and the Debian Trixie guest are installed on the observed device. P11 live acceptance passed on this device; it does not establish clean-device replay, broad device support, physical rotation behavior, or accessibility qualification.

| Area | Current reach | Remaining work |
|---|---|---|
| Shared service | Typed Native and optional PRoot operations, an explicit tested authorization and Web-session security class for every operation, exact plans, terminal broker lifecycle, and recovery | Finish the per-operation client-reach audit; clean-device replay remains open |
| CLI | Native desktop, package, SSH, recovery, graphics, Cron, guided setup, bounded CPU/Vulkan/HTP AI routes, PRoot setup/status/profile/session inspection, receipt-verified replay-guest retirement/restore, exact-plan stop, shortcut add/remove/sync/rollback, reversible legacy Turnip ICD migration, exit-proven record reconciliation, plus `tx terminal` | Clean-device Debian setup replay and remaining release qualification |
| TUI | Shared Native workflows, Debian status/profile/session/app/probe, attached-CLI setup handoff, receipt-verified replay-guest retirement/restore with exact preview and typed confirmation, exact-preview stop, shortcut add/remove/sync/rollback, exit-evidence inspection/reconciliation that never signals, optional broker setup/start, interactive terminal handoff, and bounded CPU/Vulkan/HTP routes | Fresh guest setup and legacy ICD migration remain attached Native CLI workflows; accessibility review and clean-device replay |
| Web | Authenticated loopback UI, Native management, Debian status/profile/session/probe/app, attached-CLI setup handoff, receipt-verified replay-guest retirement/restore with a dedicated `proot.replay.manage` session grant and exact preview, exact-preview stop, shortcut add/remove/sync/rollback, exit-evidence inspection/reconciliation, vendored xterm terminal, preview-confirmed broker setup/start, and bounded CPU/Vulkan/HTP routes | Fresh guest setup and legacy ICD migration remain attached Native CLI workflows; accessibility/narrow-screen review and clean-device replay |
