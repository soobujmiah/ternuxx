# Third-party artifact notices for Native workloads

**Reviewed:** 2026-10-24
**Scope:** external artifacts used by the optional Native CPU inference, experimental HTP inference, and graphics paths. This is not a complete software bill of materials for Ternuxx and does not grant a license to Ternuxx itself.

Ternuxx does not bundle or redistribute these external artifacts in a release. Termux installs and updates the CPU/Vulkan `llama-cpp` package. Ternuxx can download the pinned HTP runtime and model only after separate exact previews and explicit user confirmations; both stay in private device-local state. The graphics candidate remains a device-local extracted experiment and has no Ternuxx installer. Their terms remain separate from any license for this repository.

Before distributing a build that bundles any item, create a version-specific SBOM, include all required license texts and attribution notices, verify the exact model revision and upstream source notices, and review all transitive runtime dependencies. The links above point to upstream pages and may change; the configured mirror URL, pinned model hash, and installed package version recorded in dated evidence identify the artifacts tested for this feature. The package version was selected from a signed local APT index, but this audit did not compare the installed `.deb` byte-for-byte with the primary-host artifact.

Ternuxx itself has no selected repository license. Public repository visibility does not authorize redistribution. Choosing a project license and resolving source provenance remain owner/legal review gates documented in [LEGAL-IP.md](LEGAL-IP.md).
