# Product and commercialization readiness

This folder holds dated research and proposed commercial designs. It does not authorize a release, offer, legal policy, payment system or customer commitment. The supported source-checkout command is `./tx`; the installed command is `tx`.

## Current authorities

- [Product vision](../PRODUCT-VISION.md), [roadmap](../ROADMAP.md) and [phase state](../../project/phase-state.json) define product intent and accepted phase scope.
- [Current handoff](../../CURRENT_STATE.md), [active repository audit](../audit/REPOSITORY-AUDIT.md) and [generated Git/CI state](../../.repo/STATUS.md) identify implementation and verification progress. Dated readiness classifications do not override them.
- [Testing](../testing/README.md) separates fixture checks, device observations and workload qualification. Product source/tests exist; full reproducibility and release acceptance remain open.
- [Security policy](../../SECURITY.md) and [project instructions](../../AI_ASSISTANT.md) govern current work. A license/provenance decision remains a separate public-release gate.
